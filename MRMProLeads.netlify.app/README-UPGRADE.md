# MRMProLeads Legendary Upgrade

This package merges the original portfolio features with the new 5-case-study portfolio, public sample, methodology, privacy/data policy, performance evidence, calculators, FAQ, founder section, LinkedIn authority content, resource gallery, mobile navigation, theme toggle, print/PDF, and lightweight local assistant.

## Future image replacement
Replace:
- `assets/banner-placeholder.svg` with your original banner asset (preferred filename `banner.png`, then update the hero image source).
- `assets/mahbub-placeholder.svg` with your original founder photo (preferred filename `mahbub.png`, then update the founder image source).

No old user-facing feature was intentionally removed. Heavy libraries were replaced with dependency-free equivalents so the visual/features remain while the page avoids Chart.js/html2pdf.js and remote font loading.
