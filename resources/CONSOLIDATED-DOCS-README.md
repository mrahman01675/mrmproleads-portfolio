# Consolidated Article Documentation

The 20 per-article documentation files have been consolidated for easier maintenance.

- `SEO-METADATA-20-ARTICLES.md` — SEO title, meta, canonical, OG/Twitter and keyword records for Articles 01–20.
- `QA-20-ARTICLES.md` — article-level QA records for Articles 01–20.
- `INTEGRATION-20-ARTICLES.md` — integration records for Articles 01–20.
- `SITEMAP-ENTRIES-20-ARTICLES.txt` — the 20 article sitemap entries in serial order.

The live `sitemap.xml` remains the actual sitemap file. These consolidated files are documentation/audit records.
